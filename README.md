# VEGETRON 3000

PRODUCE ANIMATION SYSTEM · 640K

A beige 1986 workstation with one job: animate a celery stalk. Pick a program from the keypad, then confirm it with YES.

**[▶ Boot it up](https://kerosinkleber.github.io/vegetron-3000/)**
